## Calculations

- Recall = true positives / (true positives + false negatives)
- Precision = true positives / (true positives + false positives)
- Field precision = correct extracted fields / all reviewed extracted fields
- Time reduction = (current minutes − VerdaTrace minutes) / current minutes

Publish only calculated, reviewer-approved results.
